# Hi, I'm Oriol 👋

Welcome to my GitHub! This is a collection of the data, machine learning and optimization projects I have been working on over the last few years. Each one links to its own repository.

## 📂 Projects

### 🏙️ [Barcelona Housing & Urban Resilience](https://github.com/oriolparentruiz/barcelona_housing__urban_resilience)
End-to-end data pipeline that collects, formats and analyses housing, income and immigration data for Barcelona. It combines sources such as Idealista listings and municipal statistics, orchestrates the workflow with Airflow DAGs, and ends with model training and visualization.

### ⚖️ [Ethical and Engineering Implications of Automating the Ministry of Territory and Housing](https://github.com/oriolparentruiz/ethical_and_engineering_implications_of_automating_the_ministry_of_territory_and_housing)
Analysis of the ethical and engineering challenges of automating public administration processes, using the Ministry of Territory and Housing as a case study.

### 🚗 [Forecasting Monthly Car Manufacturing in Spain](https://github.com/oriolparentruiz/forecasting_monthly_car_manufacturing_in_spain)
Time series study to model and forecast the monthly car production in Spain.

### 🗺️ [Geographic Route Mapping and Medieval Monuments Routing](https://github.com/oriolparentruiz/geographic_route_mapping_and_medieval_monuments_routing)
Route planning and mapping project that works out how to connect medieval monuments through efficient geographic routes.

### 🩺 [Liver Patient Classification Using ML Methods](https://github.com/oriolparentruiz/liver_patient_classification_using_ml_methods)
Comparison of machine learning methods to classify patients with liver disease, using the Indian Liver Patient Dataset (ILPD), with the analysis documented in a Jupyter notebook.

### 📊 [Multivariate Data Analysis Project](https://github.com/oriolparentruiz/multivariate_data_analysis_project)
Application of multivariate statistical techniques to explore and interpret a real dataset.

### 🧵 [Textile Optimization](https://github.com/oriolparentruiz/texitle_optimization)
Optimization models for a textile production problem, tested on instances of three sizes (small, medium and large).
